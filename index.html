  3. JavaScript

    alpinejs-router

    Routes in your HTML. Alpine renders them.

    A client-side router for Alpine.js. Declare routes with x-route templates and x-link anchors, with dynamic params, external templates and hash or HTML5 history. No dependencies besides Alpine.

    3.2 kB
    minified and gzipped
    6.25M
    static route matches a second
    $ npm install @shaun/alpinejs-router

    Website of alpinejs-router → GitHub repository of alpinejs-router npm
